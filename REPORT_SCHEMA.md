# Report schema restored from the governed v4 concept

Fields: Report ID, reporting month, activity date, department, center/work location, workflow status, activity title, planned, actual, achievement percentage, key result, problem encountered, challenge/reason, action taken, next action, responsible person, due date, priority, data source, views/reach, engagement, new followers, evidence link, notes, submitter name/role, submission timestamp, updated timestamp.

Submitted reports are immutable for ordinary reporting roles. Full administrators may correct non-source reports. Original October source reports are preserved and cannot be overwritten.
